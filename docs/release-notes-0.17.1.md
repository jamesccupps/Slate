## Slate 0.17.1

**Download:** on Windows, `Slate.exe` below (64-bit Windows 10 or 11, signed); Slate 0.2.0 or newer offers this update in its status bar by itself. On Linux, Slate installed from its package updates with `sudo apt upgrade`; to install it, see the [README](https://github.com/jamesccupps/Slate#linux-and-raspberry-pi).

### Windows
- Slate 0.16.1 and 0.17.0 couldn't update themselves: clicking *Update* said "Couldn't update: The download isn't Slate … as the release says". The check they make on a download (that it is the version the release says) found the wrong place in the file. Those copies take this update normally, and every build is now checked the way they read it, so it can't happen again.

Nothing else changed since [0.17.0](https://github.com/jamesccupps/Slate/releases/tag/v0.17.0), which brought high contrast and other polish to the Linux version.
