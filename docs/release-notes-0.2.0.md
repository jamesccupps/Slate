## Slate 0.2.0

The first public release. Slate is a fast, simple text editor for Windows that opens files of any size: an 800 MB
JSON file opens instantly, scrolls smoothly, and can be searched, edited, formatted and saved.

**Download:** `Slate.exe` below. Run it from any folder — there's nothing to install. *Help → Open files with Slate…*
adds it to "Open with" and the right-click menu.

### What's in it
- Opens huge files instantly; only what's on screen is read and drawn.
- Tabs come back after a restart, unsaved changes included (like Windows 11 Notepad).
- Syntax colors for about 30 kinds of files: Python, PowerShell, Batch, Shell, C/C++/C#, Java, Kotlin, Swift, Go,
  Rust, JavaScript/TypeScript, PHP, Ruby, Lua, SQL, HTML, CSS, XML, Markdown, YAML, JSON, INI/TOML, CSV/TSV
  (rainbow columns), logs, diffs and Dockerfiles.
- JSON and XML: format, minify and check (also JSON Lines); a JSON path bar and structure panel.
- Find and replace with regular expressions, fast on huge files.
- Line tools: sort (natural order), remove duplicate or blank lines, trim line ends; change case; toggle comments.
- Keeps the file's encoding and line endings; notices when another program changes a file.
- Dark and light themes that follow Windows.
- Updates itself: when a new release is published, *Update* appears in the status bar.

Checksum: `Slate.exe.sha256` (SHA-256 of `Slate.exe`).
