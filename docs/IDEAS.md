# Ideas and backlog

Things that came up but aren't built yet. Add to this list whenever a new idea comes up.

## Next
- Custom title bar with the tabs in it (like Windows 11 Notepad) to save vertical space.

## Later
- Smooth (animated) scrolling.
- Files with only CR line endings (old Mac) are shown as one line with ␍ symbols; convert them on open.
- XML path bar and structure panel (like JSON's).
- Color fenced code blocks in Markdown by their language.
- A hex view for binary files (now they open as text, with a warning).
- Find in all open tabs.
- Snapshot a big file into a temp copy on the first edit, so another program rewriting it can't affect unsaved edits.
- Multiple windows; drag a tab out into its own window.
- Print.
- Unsaved files over 64 MiB: keep them in the session too (as an edit log over the original file), so closing
  never has to ask.
