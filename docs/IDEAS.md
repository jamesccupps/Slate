## Done
- JSON structure panel and path bar (lazy, fine with 800 MB files).
- App icon.
- Colors for ~30 file types, line tools, toggle comment, change case, XML format/minify/check (0.2.0).
- Updates from GitHub releases, with a checksum check; builds and release drafts on GitHub Actions (0.2.0).
- The audit round (0.3.0): unsaved work can't be lost by the session, files changed in place and lossy ANSI saves
  are caught, per-file indentation, whole-character editing, the Alt menu bar, XML whitespace kept, JSON with
  comments, updates that undo themselves if the new version can't start. See the 0.3.0 release notes.
- XML path bar and structure panel; colors for ~45 file types (VBScript/VBA, AutoHotkey, TOML, nginx, Apache, Perl,
  R, Terraform/HCL, CMake, properties, subtitles, calendars, VS solutions), Markdown code blocks in their language,
  better detection by name, folder and content (0.4.0).
